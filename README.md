# Kwalifai Social Assets

Public CDN repository for Kwalifai (NMLS 2528067, 4S Global, LLC) social media images.

This repository exists so that Buffer (and any other social scheduler) can fetch
image URLs directly via `raw.githubusercontent.com`. All images are designed for
public consumption: they are the same images that will appear on Instagram,
Facebook, LinkedIn, and YouTube.

## Structure

- `Pilot-Set-v3/` - the 80-asset social library
  - Single feed posts at root (01-25, 28, 34, 38, 39, 43)
  - `round2-carousels/` - 5 carousels (C1 through C5)
  - `round2-singles/` - 8 additional feed posts (26-33)
  - `round3-singles/` - 12 scene-narration feed posts (34-45)
  - `stories-1080x1920/` - 10 IG and FB Story images
  - `youtube-thumbnails-1280x720/` - 6 YouTube thumbnails
- Launch graphics at repo root: per-platform launch images and YouTube banner

## URL pattern

`https://raw.githubusercontent.com/4sglobal/kwalifai-social-assets/main/{path}`

Examples:

- `Pilot-Set-v3/01-wall-street-frontrun.png`
- `Pilot-Set-v3/round2-carousels/c1-5-things-rate-sites-01-cover.png`
- `fb-launch-1080.png`
